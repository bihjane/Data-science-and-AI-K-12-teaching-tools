# Intelligent Futures Free Courses

Free lessons by **Dr. Janet Bih Shufor**, Intelligent Futures. Paid courses are not included here.

| Folder | What it is |
|---|---|
| `bjs-academy-free-preview/` | Free preview of BJS Academy, as used on intelligentfutures.tech/courses. Open: Python Liftoff Module 1 and Prompt to Agent Module 1, with their lab notebooks |
| `free-lesson-video-scripts/` | Video scripts for the 7 free BJS Academy lessons |
| `free-school-lessons/` | 7 free data science and AI lessons for schools (ages 5-18), with Olympic and world population datasets |
| `colab-notebooks/` | 6 Google Colab notebooks that build real models with Python, from linear regression to a neural network |

## How to use

- **Free preview:** open `bjs-academy-free-preview/index.html` in a browser. Keep it next to its `labs/` folder.
- **Lab notebooks:** open https://colab.research.google.com, choose File > Upload notebook, and pick a notebook from `labs/`.
- **School lessons:** each Markdown file is a full lesson with a plan, handout, answer key and data.

## Full courses

Python Liftoff (PCEP and PCAP prep), Data Storytellers and Prompt to Agent (generative AI, agents and RAG) are available at intelligentfutures.tech/courses.
